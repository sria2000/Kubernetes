# Kubernetes Container Probes

A **probe** is a health check performed by the **kubelet** on containers running inside a Pod.

The kubelet uses probes to determine:

- Is the application started?
- Is the application alive?
- Is the application ready to receive traffic?

Kubernetes supports three types of probes:

1. Startup Probe
2. Liveness Probe
3. Readiness Probe

---

# 1. Startup Probe

A startup probe determines whether an application inside a container has started successfully.

It is useful for applications that:

- Take a long time to initialise
- Have slow startup times
- Require database connections or loading configuration before becoming available


Example:

```yaml
startupProbe:
  httpGet:
    path: /health
    port: 8080
  failureThreshold: 30
  periodSeconds: 10
