# 1. How do you create a Pod in Kubernetes using a YAML file?

Document: https://kubernetes.io/docs/concepts/workloads/pods/

```yaml
# Vi pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx
spec:
  containers:
  - name: nginx
    image: nginx:1.14.2
    ports:
    - containerPort: 80
```

```
root@controlplane:~$ k apply -f pod.yaml
pod/nginx created
root@controlplane:~$ k get pods
NAME    READY   STATUS              RESTARTS   AGE
nginx   0/1     ContainerCreating   0          5s
root@controlplane:~$
root@controlplane:~$ k get pods
NAME    READY   STATUS    RESTARTS   AGE
nginx   1/1     Running   0          66s
root@controlplane:~$
```
