# Kubernetes Secrets

## Overview

Kubernetes Secrets are used to store sensitive information such as:

- Database passwords
- API tokens
- Authentication credentials
- Certificates
- Private keys

Instead of storing sensitive values directly inside Pod manifests, Kubernetes provides Secret objects that can be injected into containers using:

1. Volume Mounts
2. Environment Variables

Documentation Referenced:

https://kubernetes.io/docs/concepts/configuration/secret/
