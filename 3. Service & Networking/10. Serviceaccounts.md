# Kubernetes Service Accounts

## Overview

Kubernetes has two types of accounts:

| Account Type | Used By | Purpose |
|--------------|---------|---------|
| User Account | Humans (Administrators, Developers, Operators) | Used by people to access Kubernetes cluster using kubectl |
| Service Account | Pods / Applications | Used by applications running inside Kubernetes to authenticate and communicate with Kubernetes API Server |

---

# What is a Service Account?

A **Service Account** is a Kubernetes object that provides an identity for processes running inside Pods.

Applications running inside Pods may need to communicate with the Kubernetes API Server to:

- Read ConfigMaps
- Access Secrets
- Query Kubernetes resources
- Create or update Kubernetes objects
- Interact with cluster services

For this authentication, Kubernetes provides **Service Accounts**.
