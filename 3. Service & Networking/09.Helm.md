# What is Helm?

Helm is a **package manager for Kubernetes**.

Similar to:

- apt for Ubuntu packages
- yum/dnf for Linux packages
- npm for Node.js packages


Helm simplifies deployment and management of Kubernetes applications.


---

# Why Do We Need Helm?


A Kubernetes application usually consists of multiple resources:

- Deployment
- ReplicaSet
- Pods
- Services
- ConfigMaps
- Secrets
- Persistent Volumes
- Persistent Volume Claims
- Ingress
- Load Balancers
- Service Accounts


Without Helm:


Application

|
|
+-- deployment.yaml
|
+-- service.yaml
|
+-- configmap.yaml
|
+-- secret.yaml
|
+-- ingress.yaml



Managing multiple YAML files becomes difficult.


Helm combines all Kubernetes resources into a single package called a:

# Helm Chart

# What is a Helm Chart?


A Helm Chart is a package containing:

- Kubernetes resource definitions
- Configuration values
- Templates
- Metadata


Example:

# Installing Helm on Ubuntu


## Step 1: Add Helm Repository Key


```bash
curl https://baltocdn.com/helm/signing.asc | \
gpg --dearmor | \
sudo tee /usr/share/keyrings/helm.gpg > /dev/null
Step 2: Install apt transport
sudo apt-get install apt-transport-https --yes
Step 3: Add Helm Repository
echo "deb [arch=$(dpkg --print-architecture) \
signed-by=/usr/share/keyrings/helm.gpg] \
https://baltocdn.com/helm/stable/debian/ all main" | \
sudo tee /etc/apt/sources.list.d/helm-stable-debian.list
Step 4: Install Helm
sudo apt-get update

sudo apt-get install helm
Verify Helm Installation
helm

Expected:

The Kubernetes package manager

Installing NGINX using Helm

helm repo add bitnami https://charts.bitnami.com/bitnami

Useful Helm Commands
List Installed Releases

Command:

helm list

Example:

NAME        NAMESPACE    REVISION    STATUS

my-nginx    default      1           deployed

List Helm Repositories
helm repo list

Example:

NAME        URL

bitnami     https://charts.bitnami.com/bitnami

Search Charts in Repository
helm search repo bitnami

Example:

bitnami/nginx

bitnami/mysql

bitnami/redis

Search Charts in Artifact Hub
helm search hub nginx

Searches public Helm repositories.

Render Helm Templates

Helm can generate Kubernetes YAML without installing.

Command:

helm template bitnami/nginx

Example:

helm template bitnami/nginx > nginx.yaml

Generate YAML for specific namespace:

helm template bitnami/nginx \
-n custom-ns > nginx.yaml
Uninstall Helm Release

Remove deployed application:

helm uninstall my-nginx

This removes Kubernetes resources created by the Helm release.

Helm Dry Run

Dry run allows checking generated resources before installation.

Example:

helm install my-nginx bitnami/nginx \
--dry-run
Example: Installing Argo CD using Helm

Add Argo Helm Repository:

helm repo add argo https://argoproj.github.io/argo-helm

Install with dry run:

helm install my-argo-cd argo/argo-cd \
--version 7.8.23 \
--skip-crds \
--dry-run
Working with CRDs

Check if CRDs are included:

helm install my-argo-cd argo/argo-cd \
--version 7.8.23 \
--skip-crds \
--dry-run | grep CustomResourceDefinition

Skip CRD installation:

helm install my-argo-cd argo/argo-cd \
--version 7.8.23 \
--set crds.install=false \
--dry-run

Generate manifest without CRDs:

helm template my-argo-cd argo/argo-cd \
--set crds.install=false \
--version 7.8.23 > argo-no-crd.yaml
