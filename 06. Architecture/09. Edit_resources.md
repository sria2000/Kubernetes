# Editing Existing K8s Resources

Sometimes you need to modify the config of an existing Kubernetes object — a pod, secret, configmap, etc. Two common approaches: `kubectl edit` and `kubectl patch`.

## Setup: Create a Test Pod

```bash
k run test-pod --image=nginx
```
```
pod/test-pod created
```

```bash
k get pods --show-labels
```
```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
test-pod   1/1     Running   0          41s   run=test-pod
```

## Approach 1 — `kubectl edit`

Opens the resource's manifest in your default editor for direct, manual editing.

```bash
k edit pod test-pod
```
```
pod/test-pod edited
```

Example: manually changed the `run` label from `test-pod` to `testing-pod`.

```bash
k get pods --show-labels
```
```
NAME       READY   STATUS    RESTARTS   AGE    LABELS
test-pod   1/1     Running   0          2m2s   run=testing-pod
```

This is a **manual** operation — good for one-off, interactive changes but not suited to scripting/automation.

## Approach 2 — `kubectl patch`

Used for **automation** — updates a resource in place via a JSON/YAML patch without opening an editor.

Inspect the current resource as JSON first if needed:

```bash
kubectl get pod test-pod -o json
```

Apply a patch:

**Linux:**
```bash
kubectl patch pod test-pod -p '{"metadata":{"labels":{"run":"dev-pod"}}}'
```

**Windows:**
```bash
kubectl patch pod test-pod -p "{\"metadata\":{\"labels\":{\"run\":\"dev-pod\"}}}"
```

### Verifying the Change

Export the pod spec and confirm the current label:

```bash
k get pods test-pod -o json > sri.json
grep -i testing sri.json
```
```
            "run": "testing-pod"
```

Patch the label:

```bash
k patch pod test-pod -p '{"metadata":{"labels":{"run":"staging-pod"}}}'
```
```
pod/test-pod patched
```

Confirm:

```bash
k get pods --show-labels
```
```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
test-pod   1/1     Running   0          7m    run=staging-pod
```

## Summary

| Approach | Use Case | Style |
|---|---|---|
| `kubectl edit` | One-off, interactive changes | Manual |
| `kubectl patch` | Scripted/automated updates | Automation-friendly |
